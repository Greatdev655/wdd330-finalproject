# wdd330-finalproject
 
Building a book tracker app that allows users to find books and  track their reading habit
it doesn't make use of extra features such as acct sign up,review or sharing. it's just straight to the point, user search for a book by tittle or author, recomendations are displayed(ion image thumbnail), details are accessible by clicking the image and a modal is displayed , in the modal is a add to library btn. 
when clicked , it add the book to user library with a label of reading . on completion , user clicks the finished btn to change label from reading to finished.
